# Bold View — dataset citations

Status: **built 2026-07-19** (app display live; table load is a manual owner step).

The deliberately small replacement for the shelved relational citation model
(see `citation-model.md` for that history). Rather than model works/people/etc.
in Postgres, bold-view surfaces **one** useful slice: the publications that cite
a BOLD dataset. The rich citation/curation graph lives in a triple store instead.

## Data source

`~/Development/bold-dataset-citations/results/citations.csv` — regenerated by the
`bold-dataset-citations` project (which owns this data). ~1,758 rows covering
~1,587 datasets. One row = one citing work, identified by whatever it has:

```
dataset,dataset_doi,doi,handle,urn,url
DS-070222,10.5883/ds-070222,10.3390/d14030182,,,https://www.mdpi.com/1424-2818/14/3/182
```

- `dataset` — `DS-*`, the join key to the app's recordset/dataset view.
- `dataset_doi` — the dataset's own DOI (`10.5883/ds-*`).
- `doi` / `handle` / `urn` / `url` — identifiers/locators of the **citing** work
  (doi present in ~94% of rows; url is the common fallback; handle/urn rare).

## Table (owner-privileged — the app role can't create it)

The app connects as `boldview_app`, which is read-only by design (see
db-hardening work). So the table is created + loaded once with the **owner** role.
The table mirrors the CSV 1:1 — a row stays one citing work with its identifiers.

```sql
CREATE TABLE dataset_citation (
  dataset      text NOT NULL,   -- DS-*  (join key to the recordset view)
  dataset_doi  text,
  doi          text,            -- citing work (~94% of rows)
  handle       text,
  urn          text,
  url          text
);
CREATE INDEX dataset_citation_dataset_idx ON dataset_citation (dataset);
GRANT SELECT ON dataset_citation TO boldview_app;   -- app reads it
```

Load / reload (the CSV is regenerated, so truncate-and-reload is fine). Run in
psql connected as the owner, from the `bold-dataset-citations` directory:

```
TRUNCATE dataset_citation;
\copy dataset_citation (dataset,dataset_doi,doi,handle,urn,url) FROM 'results/citations.csv' WITH (FORMAT csv, HEADER true)
```

## App display (built, read-only)

- `core.php`:
  - `get_recordset_citations($id)` — reader; guarded with `to_regclass` so it
    returns `[]` (no errors) until the table is loaded. Returns structured link
    data, not HTML.
  - `citation_row_to_link($row)` — picks the most resolvable identifier per row
    (`doi > url > handle > urn`) and builds `{href, label, kind}`. DOIs →
    `https://doi.org/…`, handles → `hdl.handle.net`, urns → `nbn-resolving.org`.
- `index.php` `display_recordset()` — a "Cited by" section listing the links,
  shown only when there are citations.

Not exposed via the API/v1 yet — recordset web view only, by design (keep small).
